# Student Complaint Portal

A full-stack MERN application for managing student complaints within educational institutions.

## Features

- Student Registration and Login
- Complaint Submission
- View Complaints
- Admin Dashboard
- Update Complaint Status
- Delete Complaints
- MongoDB Database Integration

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- Axios

## Project Structure

student-complaint-portal/
│
├── client/

## Installation

### Backend

cd server
npm install
npm start

### Frontend

cd client
npm install
npm run dev
